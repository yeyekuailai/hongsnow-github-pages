# HongSnow Coaching

Static public site for HongSnow snowboard coaching.

Deploy with GitHub Pages from the `main` branch root.

## Repository sites

- `/` — HongSnow coaching site
- `/coach-marketplace/` — SnowLink bilingual coach marketplace prototype
- `/aasi-exam-guide/` — bilingual AASI assessment guide

Each subsite is self-contained and uses relative asset paths so GitHub Pages can publish it directly from the same repository.

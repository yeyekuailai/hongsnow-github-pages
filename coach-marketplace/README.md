# 雪语 SnowLink — Prototype

面向中国滑雪用户的全美官方雪校中文教练导航原型。

## 当前包含

- 中文教练首页与雪场导航
- 雪场、单双板、语言和教学对象筛选
- 教练验证、课程记录与复购信息
- 教练详情和指定教练英文请求模板
- 跳转雪场官网订课
- 教练入驻与登录占位交互
- Epic / Ikon 全美雪场地图与通票、州、雪场联动筛选
- 独立四步教练主页申请页
- Google Apps Script → Gmail 申请收件后端
- 桌面端、平板和移动端响应式布局

## 本地预览

在本目录运行：

```bash
python3 -m http.server 4173
```

然后访问 `http://localhost:4173`。

教练申请页位于 `apply.html`。Gmail 收件配置见 `BACKEND_SETUP.md`。

## 产品边界

本原型不销售课程、不处理付款，不代表任何雪场或 PSIA-AASI。示例教练资料为产品设计占位内容，正式发布前必须替换为获得本人授权并经官方雪校身份验证的真实资料。

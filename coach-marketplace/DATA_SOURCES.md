# 雪场数据来源

更新时间：2026-08-17

当前 `resorts.js` 收录 78 个美国通票目的地：

- Epic Pass：37 个，包括美国自营目的地及美国合作目的地 Telluride。
- Ikon Pass：41 个美国目的地。

官方来源：

- Epic 美国自营雪场与区域目录：https://www.epicpass.com/regions/.aspx
- Epic 合作雪场目录：https://www.epicpass.com/regions/partner-resorts.aspx
- Ikon 全球目的地目录：https://www.ikonpass.com/en/destinations

部分通票目的地包含多个山体或相邻雪场，例如 Aspen Snowmass、Killington - Pico、Big Bear Mountain Resort。当前数据遵循通票官网的“目的地”口径，不把其内部山体拆成多个筛选项。

通票名单、合作关系和名称可能逐雪季变化，上线后应在每年新雪季通票发布时复核一次。
